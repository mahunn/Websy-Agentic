# WEBSY AGENT DIRECTIVES & SYSTEM RULES

See detailed guidelines in [AGENT_RULES.md](file:///e:/WEB-DEV-Business/Websy-Agentic/AGENT_RULES.md).

## Quick Summary
1. **Design System**: Dark Obsidian theme (`#0C0D0E` base, `#141619` cards, `#1E2024` elevated surfaces) with Burnt Ember (`#E25C38`) primary accent.
2. **Typography**: `Plus Jakarta Sans` for headlines (`font-display`) and `Geist` for body text (`font-sans`).
3. **No Generic AI Tropes**: No purple/cyan glows, no generic 3-column equal cards, no placeholder text.
4. **Layout**: High-density asymmetric Bento grids with real metrics and domain-specific copy.
